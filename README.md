# E-commerce Database Analysis (SQL & SQLite)

## About The Project
This project simulates an e-commerce database environment to analyze customer purchasing behavior, regional sales performance, and product popularity using SQL queries.

## Key Technologies
- **SQL / SQLite**
- **Pandas** (Data Display & Result Extraction)

## SQL Concepts Demonstrated
- Relational schema creation and data insertion (`CREATE TABLE`, `INSERT INTO`, `FOREIGN KEY`).
- Data aggregation and grouping (`SUM`, `JOIN`, `GROUP BY`, `ORDER BY`).
- Advanced window functions (`ROW_NUMBER() OVER (PARTITION BY ... ORDER BY ...)`).

## Project Structure
- `sql-ecommerce-analysis.ipynb` — SQLite database setup script and executed business analytical queries.

## How to Run
1. Download the `.ipynb` file or clone the repository.
2. Open it in Google Colab or Jupyter Notebook.
3. Run all cells sequentially to recreate the database and view the query outputs.
